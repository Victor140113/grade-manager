Endpoints

Mapa visual da API atual do Grade Manager.

localhost:8080

Grade Manager

Criação, listagem e remoção.

GET
/grade-managerLista os GMs
POST
/grade-managerCria um GM · body { nome }
DELETE
/grade-manager/{gmId}Exclui um GM

Semester

Semestres pertencem a um GM.

GET
/grade-manager/{gmId}/semesterLista os semestres
POST
/grade-manager/{gmId}/semesterCria um semestre
DELETE
/grade-manager/{gmId}/semester/{semesterId}Exclui um semestre

Course

Matérias pertencem a um semestre.

GET
/grade-manager/semester/{semesterId}/courseLista as matérias
POST
/grade-manager/semester/{semesterId}/courseCria matéria + suas Grades
DELETE
/grade-manager/semester/{semesterId}/course/{courseId}Exclui matéria

Grade Update

Atualizações alteram o valor acumulado da Grade.

GET
/grade-manager/semester/course/grade/{gradeId}/grade-updateLista os updates
POST
/grade-manager/semester/course/grade/{gradeId}/grade-updateAdiciona pontos
PUT
/grade-manager/semester/course/grade/{gradeId}/grade-update/{guId}Edita um update
DELETE
/grade-manager/semester/course/grade/{gradeId}/grade-update/{guId}Remove pontos e o update

Exemplo · POST

Criar um Grade Update.

POST /grade-manager/semester/course/grade/7/grade-update { "description": "Prova", "value": 5.0 }
